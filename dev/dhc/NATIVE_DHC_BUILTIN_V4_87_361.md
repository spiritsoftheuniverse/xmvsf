# XMVSF 87.361 — completed native DHC is built into Version 4

The completed 87.360 original US native 68000 DHC path automatically runs when Version 4 is selected in xmvsfu. No setup flags are needed: XM87274_UNIFIED_DHC, XM87334_MORPHUS_PRECOMMIT, XM87335_NATIVE_DHC and XM87340_MORPHUS_NATIVE no longer control this production feature.

The native code still checks the genuine US driver, original opcode/exit site, actual outgoing 2C/2E Hyper, real incoming original PP/KK/KKK input, live partner, stock and original M68K tag/Hyper completion. DHC gesture matching remains inactive during normal fighting. Charlie QCB+KKK, Chun-Li's complete grounded Senretsukyaku lifetime and Sabretooth's HCB+KKK are unchanged from 87.360. Version 3 and other ROM sets are not modified by this integration.

RUN_TEST.bat now prints built-in Version-4 behavior and no longer forces XM87274_UNIFIED_DHC=0. The optional observer log path remains configurable. BUILD_TEST.bat and local Make build now use test version 87.361. No new mandatory build tests, GitHub Actions or Stable binary writes.

The Windows build and fresh flagless runtime must still be run locally before claiming a new binary has been tested.
